                      商品价格监控系统  使用说明
================================================================
版本：1.5.0
作者：安安
支持平台：淘宝 / 天猫 / 京东 / 拼多多 / 抖音商城
支持浏览器：Google Chrome / Microsoft Edge


----------------------------------------------------------------
一、这个软件能做什么
----------------------------------------------------------------
自动打开浏览器，定时抓取你关注的商品价格，记录下来并画成走势图，
价格降到你的预期价时弹窗 + 播放提示音提醒你，同时把每次抓取结果
存进 Excel 表格，方便你回看和统计。

最多可同时监控 20 个商品链接。


----------------------------------------------------------------
二、第一次使用（按顺序做这 5 步）
----------------------------------------------------------------

【第 1 步】选择浏览器
    双击「商品价格监控系统.exe」。
    第一次启动会弹出窗口，列出你电脑上已安装的浏览器（Chrome / Edge），
    选一个然后点「使用这个浏览器」。
    · 如果不想每次都问，勾选「记住这次选择，下次启动不再询问」。
    · 想换浏览器：点主窗口右下角的「当前浏览器：xxx · 更换」。

【第 2 步】登录购物平台（重要！不登录抓不到价格）
    点工具栏的「登录平台」按钮 → 在下拉框选平台 → 点「打开登录页面」。
    会弹出一个真实的浏览器窗口，在里面正常登录（扫码 / 账号密码都行）。
    登录成功后程序会自动检测并保存登录状态，弹窗提示「登录成功」。
    · 淘宝和天猫是同一个账号体系，登录一次通常两个都能用。
    · 每个平台都需要单独登录一次。
    · 登录状态保存在程序目录的 data 文件夹里，下次启动自动恢复，
      不用每次重新登录。失效了再点一次「登录平台」即可。

【第 3 步】添加商品
    点工具栏的「添加商品」按钮，然后：
    ① 商品链接：在浏览器里打开商品页，复制地址栏完整链接粘贴进来。
       （支持淘宝、天猫、京东、拼多多、抖音商城的商品链接）
    ② 预期价格：你想在多少钱以下被提醒，填数字即可。
       填 0 表示只看价格、不提醒。
    ③ 刷新方式，二选一：
       · 每日刷新：比如每天 10:00 抓一次
       · 间隔刷新：每隔 N 小时 / 每隔 N 分钟抓一次
         ⚠ 分钟模式最少 15 分钟。因为 20 个商品抓一轮就要 5~7 分钟，
           间隔太短会出现"上一轮没刷完、下一轮又到期"的堆积。
    点「确定」后程序会立刻去抓一次价格。

【第 4 步】看价格
    左侧表格会显示：商品名称、平台、当前价格、预期价格、上次刷新时间、
    下次刷新倒计时、刷新设置、状态（监控中 / 已达标 / 待刷新）。
    点某一行，右下角的「走势图」标签页会显示这个商品的历史价格曲线，
    绿色虚线是你的预期价格。

【第 5 步】看记录 / 导出表格
    右下角「价格记录表」标签页显示所有商品的全部抓取记录。
    · 程序会自动把记录写进程序目录的 price_records.xlsx，无需手动保存。
    · 想另存一份：点工具栏「导出记录表」→ 选择位置和文件名，
      支持 .xlsx 和 .csv 两种格式。
      导出的表格里价格是数字格式，可以直接在 Excel 里求和、排序、画图。


----------------------------------------------------------------
三、其他功能
----------------------------------------------------------------

● 立即刷新
  点工具栏「立即刷新」，把所有商品重新抓一遍（正在抓的时候点会提示等待）。

● 提示音（价格达标时播放）
  点工具栏「提示音」→ 选一个 mp3 / wav / ogg / flac 文件。
  之后某个商品价格 ≤ 预期价时，会弹出提醒窗口并循环播放这段音乐，
  点「我知道了」或直接关掉窗口就停止播放。
  提示音路径记录在 data\config.json 里。如果原文件被删掉或挪了位置，
  下次启动会自动清空设置，重新选一次即可。

● 右键菜单（在左侧商品列表上点右键）
  编辑设置 / 刷新此商品 / 打开商品链接 / 删除商品

● 再次启动时
  之前添加的商品、刷新设置、登录状态都会自动恢复，直接就是上次的样子。


----------------------------------------------------------------
四、程序目录里都有什么
----------------------------------------------------------------

  商品价格监控系统.exe     主程序（双击运行）
  _internal\               程序依赖文件，不能删、不能单独移动
  使用说明.txt             就是本文件
  data\                    你的数据（首次运行自动创建）
    products.json            商品列表与历史价格
    config.json              设置（提示音、浏览器选择等）
    cookies\                 各平台的登录凭证
    chrome_profile\          Chrome 浏览器的登录状态
    edge_profile\            Edge 浏览器的登录状态
    drivers\                 浏览器驱动缓存
  logs\                    运行日志（出问题时可以看这个）
  price_records.xlsx       自动生成的价格记录表

想"恢复出厂"：关掉程序，删掉 data 文件夹和 price_records.xlsx 即可。

五、常见问题
----------------------------------------------------------------

Q1：添加了商品，但价格一直显示 "--"
   多半是没登录，或登录已过期。点「登录平台」重新登录一次。
   也可以点右键 →「刷新此商品」再试。
   日志文件 logs\app_日期.log 里会记录失败原因。

Q2：某些商品没有"原价"
   原价来自商品页上显示的「优惠前」或划线价。如果该商品页面本身
   没有打折信息（比如只有"直接下单享优惠"），就抓不到原价，
   这是正常的，不影响当前价格的记录。

Q3：提示"价格记录文件正被 Excel 占用"
   你正用 Excel 打开着 price_records.xlsx。程序不会丢数据：
   关掉 Excel 后会自动补写。建议把表格另存一份再看，
   或者直接点「导出记录表」导出到别处查看。

Q4：第一次用 Edge 时卡了一会儿
   Edge 的驱动需要联网下载，约 11MB，只在第一次或 Edge 升级后发生。
   之后再启动就是秒开。

Q5：抓一轮要多久？
   单个商品约 15~20 秒（要真实加载页面）。20 个商品一轮约 5~7 分钟。

Q6：为什么有商品价格降到预期价却没提醒？
   提醒只在"抓取到新价格"时判断一次。如果提示音没设置，只会弹窗不会响。
   另外刷新间隔内产生的降价，要等下一次抓取才会被发现。

Q7：程序能开多个吗？
   不建议。多个实例会争抢同一个浏览器登录目录，容易报错。
   想监控更多商品，改刷新间隔就行。
